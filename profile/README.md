# Code School of Guam Alumni

This organization is the shared learning and building space for Code School of Guam graduates. Use it to revisit class material, find current setup and development guides, study runnable examples, and keep building with other alumni.

## Start here

1. Open the [CSG Learning Platform](https://learn.codeschoolofguam.com) for the full alumni curriculum, lesson summaries, focused recording timestamps, and optional practice.
2. Use the private [Resources](https://github.com/Code-School-of-Guam-Alumni/Resources) repository for current setup, Rails, React, deployment, AI engineering, and production-app guides. The [Find a Guide](https://github.com/Code-School-of-Guam-Alumni/Resources/blob/main/FIND_A_GUIDE.md) index is the fastest way to locate a specific topic.
3. Browse [Learning Examples](https://github.com/Code-School-of-Guam-Alumni/Learning-Examples) for runnable reference code and exact code snapshots matched to class recordings.

The alumni library is optional and self-paced. There are no deadlines, grades, or required submissions.

## Build with the alumni community

[Party Games Hub](https://github.com/Code-School-of-Guam-Alumni/party-games-hub) is the current shared alumni project. Alumni builders can contribute through small branches and reviewed pull requests while practicing the same Rails, React, testing, and collaboration workflow used in class.

## Access and contributions

- Alumni members can read the private guide library.
- Learning Examples and Party Games Hub are public.
- Changes go through pull requests so the guides, examples, and shared projects stay reviewable.
- If you cannot open the private Resources repository after joining, contact Leon so your organization membership and team access can be checked.

Code School of Guam alumni can keep using these materials as the curriculum grows. New lessons and updated recommendations will appear in the learning platform and repositories over time.
